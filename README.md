## ✨ Features

- 💬 Chat with your codebase for instant context
- ⚡ Fast, minimal editor focused on developer flow
- 🧠 Designed to reduce context switching while coding

---

## 🚀 Getting Started

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```
